# 关于本目录

`case-forge`（案例锻造官）是我独立设计并撰写的 Agent Skill。

- **独立仓库**：https://github.com/sxr-design/case-forge （独立发布，持续维护，本目录为快照副本）
- **许可证**：MIT
- **定位**：求职材料管线的下游——把项目素材经证据分级后锻造成作品集案例与面试叙事，防止模板化写作与证据夸大。
- **姊妹项目**：`../jd-translator/` 负责上游（JD 聚类与简历分版）。
- **设计参考**：工作流模式参考了 impeccable 等公开项目的写法，全部内容为原创，详见本目录 README 的"设计参考"一节。
